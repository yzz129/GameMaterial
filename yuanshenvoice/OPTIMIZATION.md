## 视觉约束

保留原神的深色、金色与元素识别；采用安静的档案馆布局。界面字号、间距和按钮统一，角色图片承担主要视觉。设计参数：布局变化 6 / 持续运动 1 / 信息密度 5。页面自身不再请求外部字体、脚本或图片；原声包下载访问第三方，浏览器朗读是否联网由设备语音服务决定。

## 资源和重建

- `assets/manifest.json` 记录素材来源、用途、尺寸、版本、版权归属与 SHA-256。
- `assets/masters/` 保留源图片；页面只读取 `assets/characters/` 等运行资源。
- `teyvat_characters.json` 与旧数据文件保留，运行数据在 `data/`。
- `npm run prepare:assets` 从现有数据库及素材源重建资源，首次需要网络。
- 修改页面或运行数据后执行 `npm run build`，更新压缩副本与素材校验值。
- `npm test` 验证数据完整性、压缩响应、缓存、范围请求与路径处理。

## 验证范围

自动检查覆盖 96 位角色本地资源、台词计数、索引保留、全文检索一致性、压缩解码、条件请求、音频范围请求、错误路径与私有文件访问。

浏览器检查覆盖全文搜索、匹配分类、复制、收藏和刷新持久化、PNG 海报导出、朗读的暂停/恢复/切换、明暗主题及独立索引页。检查了 320、390、768、1440、1920 像素宽度，修复了最窄屏幕的横向溢出。未使用实体 iPhone 或 Android 设备；浏览器朗读依赖设备已安装的语音服务。无本地原声文件时不会发起不存在的音频请求。第三方原声包的下载地址沿用原始数据库，没有下载整包或验证其中每个文件。

本地浏览器记录：页面节点从 3,317 个减少到 662 个，初始仅挂载 24 张角色卡片，无持续 CSS 动画。冷启动检查没有图片失败、横向溢出或控制台错误。目录实际压缩响应为 27,374 字节，默认今日台词详情为 6,277 字节；全文搜索索引未在首屏请求。导航事件测得 DOMContentLoaded 34ms、load 53ms，这些仅是当前电脑 localhost 的结果，不能视为移动网络或真实设备成绩。原始记录在 `_qa/performance.json`。

最终 `npm test` 的 6 项检查通过，主程序、搜索 Worker 和服务器均通过语法检查。PNG 海报实际导出并检查为 900 × 1,150 像素，独立语音索引验证了铃声筛选、全文匹配、收藏刷新保留、取消收藏与第 2 页从第 37 条开始。

## 星辉玻璃与典藏金卡（2026-10-22 后续）

按后续需求加入蓝色透明玻璃、细金边、星轨纹样和典藏卡框。标题采用本机可用的中文衬线字体、加重字形与疏朗字距，营造原神菜单和祈愿的视觉氛围；没有新增外部字体请求，也没有内置游戏专有字体。明暗主题共用同一套层级，正文与卡片元数据保持清晰。

角色卡片加入随鼠标移动的虹彩反光、分层倾斜、金色边缘和投影。事件在图鉴容器统一管理，每次指针输入至多请求一帧，停下后没有帧循环；同一时刻只有一张卡启用 3D，其余卡片为平面。离开卡片、滚动、调整窗口、切换系统动态偏好和隐藏页面时都会复位。卡片与标题仅播放一次入场，结束后释放动画状态。

桌面正常页面只在页头和筛选面板使用背景模糊，打开详情时关闭这两处模糊，仅保留详情本身。767px 以下关闭背景模糊，触屏取消实时倾斜并保持直接点击。系统要求减少动态时禁用倾斜和入场动画，减少透明度时使用实色面板。没有加入持续粒子、全屏滤镜或动画库。

本轮浏览器检查了 320、390、768、1440px 宽度，均无横向溢出；检查了明暗主题、触屏指针模拟下的一次点击打开、详情立绘渐隐、全文搜索、跨页返回后再次搜索与减少动态模式。未进行实体手机测试。桌面测得 24 张卡片在静止时均为平面，悬停时只有一张开启 3D；鼠标停止的 700ms 观察窗口内，新增 requestAnimationFrame 调用为 0，持续运行的动画为 0。这是本机浏览器观察，不代表所有设备的帧率成绩。

预览在 `_qa/gold-glass-desktop.png`、`_qa/gold-glass-mobile.png` 与 `_qa/gold-glass-mobile-detail.png`；改版前源码备份在 `_backups/2026-10-22-gold-glass/`。本轮重新生成压缩副本，并再次执行原有 6 项完整性与服务检查。

## 通透云海、科技微粒与点击反馈（后续需求）

进一步降低云海遮罩和面板底色的不透明度：桌面页头从 58% 降为 35%，筛选面板从 58% 降为 32%；手机保留 48% 的底色以保证文字可读。角色资料正文保持较稳定的底色，图片、标题与金卡层级沿用上一版。

星尘用于表现星轨与数据微粒的空间感，采用一个 Canvas、固定容量的 Float32Array 和固定随机种子，绘制少量点、定位标记与近距离短线。桌面最多 36 个粒子、7 条连线、每秒最多 20 次绘制；手机最多 14 个粒子、3 条连线、每秒最多 12 次绘制；低能力设备降至 10 个粒子和每秒 10 次。像素比不超过 1.25，Canvas 总像素限制约为 260 万。没有新增图片、字体、动画库或网络依赖。

页面隐藏、打开角色详情、滚动期间与页面离开时停止调度；返回可见页面或关闭详情后恢复。右上角星形按钮可以关闭星尘及点击光环，选择保存到本地。减少动态、节省流量或 Canvas 不可用时使用静态背景。点击光环采用 4 个复用槽位，每次约 440ms，结束后移出页面；不会拦截指针事件或改变业务操作。

浏览器观察：桌面 1,107ms 内绘制 18 次；打开详情与关闭效果后的 700ms 观察窗口内均绘制 0 次，关闭效果后新增 requestAnimationFrame 调用为 0。验证了关闭选择在刷新后保留、减少动态时无光环、320/390/768/1440px 无横向溢出，以及触屏指针模拟下直接打开详情。未测试实体手机，也未将本机观察视为跨设备帧率保证。

验证中修正了光环给固定定位关闭按钮添加 relative 定位的问题：现在仅为原本 static 的控件增加定位上下文。最后的浏览器点击复测因 Work 设置关闭浏览器控制而未完成；修正后的代码已通过语法检查与现有 6 项自动检查。记录在 `_qa/atmosphere-checks.json`，界面预览在 `_qa/particle-click.png` 与 `_qa/atmosphere-mobile.png`。本轮改动前备份位于 `_backups/2026-10-22-particles/`。

## 动态星海背景与角色全身展台（2026-10-22）

桌面与手机均可播放即梦生成的循环视频背景，并保留静态海报与手机静帧作为首帧、失败和节能回退。视频以原始 H.264/MP4 字节直接发布（1248×704、约 8 秒、无音轨），经 ffprobe 检查并完整解码。服务端支持视频 MIME 与 Range 请求，播放器按需加载，滚动、页面隐藏、详情打开或关闭效果时暂停；视频播放时停用重复的 Canvas 粒子绘制。省流量、2G 网络、系统减少动态、极低内存设备和视频不可用时回退到静态场景。

为 96 位角色补齐透明全身祈愿立绘，并在详情页改用全身图。角色视觉由人物、光环、元素徽记和展台分层构成，轻微指针视差只由单次输入触发；切换为全屏欣赏后可返回台词详情。详情模态框在窄屏改为上下布局，立绘使用 contain 约束，人物不会再被原来的固定半身预览区域裁切。手机金卡使用静态虹彩箔面、元素色辉光、立绘阴影和金属细边；触摸期间才启用短暂 3D 分层抬升，避免整组角色卡常驻 GPU 动画。动效遵循减少动态设置，并复用已有场景开关。

`npm run build` 成功，`npm test` 的 16 项检查通过；DOM 检查确认支持条件下的手机会请求并播放静音循环视频，减少动态、省流量及用户关闭效果时维持静态回退。视频通过完整解码和精确字节哈希检查，静态立绘检查图在 `_qa/full-art-review.png`。8080 的页面、脚本、样式、视频 Range 请求、海报、手机静帧及全身立绘均以本地 HTTP 验证。由于当前 Work 设置禁用了浏览器自动化，无法在这轮读取实际浏览器截图；没有进行实体手机测试。
