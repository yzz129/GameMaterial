网络验证逐个发送小范围请求，核对 HTTP 成功响应、非空文件大小和 WAV/MP3 等文件签名；没有把 HTML 错误页当成音频。源接口取得 150 个新响应，未使用旧快照回退；5 个官方英雄接口返回 404，均属于已列出的无音源档案。官方音乐目录和 QQ Music 歌曲源也重新读取核对。

页面路由测试为了避免重复下载数 GB 音频，仅在隔离浏览器内替换媒体传输，逐个触发真实页面按钮并比较请求地址；真实解码、播放、拖动、暂停与音量由独立浏览器回归测试验证。网络音频头检查、全量路由检查、实际播放检查是不同的证据，没有用替换媒体传输的测试冒充实际播放。

本报告证明站点记录与官方发布数据、页面播放器路由的对应关系，以及检查时全部目录音源的可访问性。**未逐句人工听辨或语音转写全部 18,159 条，不能排除官方原始标注自身存在错误，也未完整解码所有长音频。**

## 明确的缺口

- 女娲「至高创世」的「神会做自己该做的事。」在官方数据中没有音频地址，已排除出可播放目录，未用其他录音替代。
- 13 份档案暂无官方可用语音：大禹、盾山、空空儿、卢雅那、梦奇、王维、心魔六耳、影，以及元流之子的刺客、法师、辅助、射手、坦克五种职业。
- 1,301 首歌曲只有 QQ Music 官方歌曲页，保持平台跳转标识，未伪装为站内完整播放。

## 本轮修正

- 皮肤切换时同步插画、图注和该皮肤的展示/战斗语音数量。
- 旧弹窗的延迟 `close` 事件在新弹窗打开后不再取消新英雄的加载，播放器也不会被错误移出新弹窗。
- 每个原声按钮保留稳定的语音 ID，可直接对应数据记录与播放器请求。
- 曲库时长与播放器使用同一份实测结果，保留官网原始标注供追溯。

## 复查

```sh
npm run audit:audio
npm run test:routing
npm run test:browser
npm run test:music-media
```

`audit:audio` 会重新核对官方源数据，并复用 24 小时内已成功的媒体探测。需要全部重新探测时执行 `node scripts/audit-audio.mjs`（不带 `--resume`）。浏览器测试通过环境变量 `PLAYWRIGHT_MODULE` 和 `PLAYWRIGHT_EXECUTABLE` 指定已有安装。

机器可读摘要：`data/audio-audit.json`。每个 URL 的响应状态、音频格式、文件大小、时间和引用记录：`source-snapshots/audio-audit/report.json`。页面路由结果：`docs/audio-routing-verification.json`。真实播放与截图：`docs/browser-verification.json`。
