# 门户场景动效

门户保留原插画与书法素材，通过共享的 `portal/portal-motion.js` 为每张插画施加独立的局部动作。角色脸部、手持兵器等固定区域保持稳定，头发、衣摆、披风和光带分别摆动；这是基于原画的实时局部动画。

## 当前场景

| 场景 | 动作与素材 |
| --- | --- |
| 首屏 | 星光明暗变化、云层与树叶局部流动、两条低频流星；沿用原 AE 渲染的水晶标题 |
| 原神 | 已有 2K 横屏／竖屏风起地视频；派蒙悬浮、发梢与披风摆动、光带流动 |
| 王者荣耀 | 李白长发与衣摆摆动、凤凰羽翼与光焰流动；固定脸部、右手与剑身，前景花瓣飘落 |
| 书法 | 「选择你的世界」「王者荣耀」「让热爱，有迹可循」在原透明字形内部掠过柔光 |
| 页脚 | 沿用极光云海视频，书法柔光与装饰曲线缓慢呼吸 |

所有动作自动播放，触屏无需悬停。页脚「暂停页面动效」控制角色、粒子、书法、AE 标题与两处视频，并记住手动暂停偏好。系统减少动态效果或节省流量时默认静止，用户可主动开启。搜索、游戏入口与原始文案不变。

## 新游戏配置

每款游戏在 `game.config.json` 的 `portal.art` 里配置素材和动作；共享代码不按游戏 ID 分支。

- `backgroundMotion`：背景插画或包含角色的整幅插画的动作区域
- `characterMotion`：透明独立角色的动作区域
- `video.desktop` / `video.mobile`：可选场景视频，路径相对于游戏目录；只在进入视口后加载
- 门户首屏的动作区域在 `portal.config.json` 的 `backgroundMotion`

动作配置采用原图坐标，左上角为 `[0, 0]`，右下角为 `[1, 1]`：

```json
{
  "light": 2,
  "regions": [
    { "area": [0.32, 0.24, 0.18, 0.16], "motion": [0.006, 0.003, 0.85, 0] }
  ],
  "locks": [[0.5, 0.25, 0.1, 0.08]],
  "lines": [{ "points": [0.3, 0.2, 0.9, 0.8], "width": 0.016 }]
}
```

`area` 是中心及横纵半径，`motion` 是横纵振幅、角速度和相位。最多 8 个动作区域、4 个固定椭圆、2 条固定线段。`light` 为 0 时关闭额外光效，1 为星光、2 为蓝色光带、3 为暖色光焰。固定区域用于保护人物面部、手部与兵器，避免整张画面的形变传入这些部位。

## 运行与降级

WebGL 仅初始化进入视口的画面，纹理上传一次，帧循环只更新时间。画布像素比不超过 1.5，桌面最多 150 万像素／30fps，手机最多 70 万像素／24fps，低性能设备最多 45 万像素／20fps。屏幕外、后台或全局暂停时不继续绘制；离开页面释放观察器、事件和 GPU 资源。WebGL 不可用或上下文丢失时显示原图，视频失败时显示海报。

视频沿用已审核的 2K 原素材，构建分片保持原始字节并支持范围请求，不为部署重复压缩。来源、母版与素材清单仍由各游戏原有资产记录管理。

验证命令：`node --test tests/*.test.mjs`、`node tools/portal.mjs build`。浏览器验收覆盖手机 320px／390px、桌面布局、竖屏视频选择、局部场景帧推进、全局暂停与恢复、离屏暂停、减少动态效果，以及控制台错误。
